# Cross-check: gerefscipe – habban (pp. 97–107)

The entries from *gerefscipe* to the start of *habban* were checked against the team's Word transcription, *gerefscipe - habban.docx* (13 October 2026), in the same way as [A – boc](crosscheck-A-boc.md). The document begins with the end of *gerefa*, which matches the site apart from three slips in the Word document (hames gerefa, 30,1 without its semicolon, Vorsitzende), and ends partway through *habban*.

The earlier Word documents were run again with the fix and give the same result as before.
